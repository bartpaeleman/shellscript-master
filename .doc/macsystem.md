# macOS System (`modules/macos/macsystem/`)

Bevat systeembeheer-scripts voor macOS:
- `macmanager.sh`: Centraal menu voor macsystem.
- `crontab_manager.sh`: Crontab-taken beheren.
- `zshrc_editor.sh`: `~/.zshrc` configuratie bewerken.
- `auto_cleanup.sh`: Periodieke systeemopschoning.
- `clear_cache.sh`: Caches opschonen.
- `uninstall.sh`: Applicaties volledig verwijderen.

### Gebruik
```bash
./master macsystem
./master macsystem clear_cache
```
